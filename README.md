# Lahore 3D Driving Simulator (Phase A)

Godot 4.2+ proof of concept: ek car, ek road + intersection, 2 cameras, touch controls, speedometer.

## Controls
- Touch: < > (steer), GAS, BRAKE, HAND BRAKE, D/R (drive/reverse), CAM (camera), II (pause)
- PC test: W/A/S/D ya arrows, Space = handbrake, C = camera

## Run
1. Godot 4.2+ kholein, "Import" -> `project.godot` select karein.
2. F5 dabayein.

scenes/ scripts/ assets/ map_data/ docs/
